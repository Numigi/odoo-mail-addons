==================================
Mail Bounce Catchall Multi Company
==================================


.. |badge1| image:: https://img.shields.io/badge/maturity-Beta-yellow.png
    :target: https://odoo-community.org/page/development-status
    :alt: Maturity: Beta

|badge1|

This module fixes an issue in Odoo 14 Multi-Company environments where bounce emails
generated by the catchall (when no alias is found) always reference the default
environment company instead of the company associated with the receiving domain.

**Problem:**
If you have Company A (domain-a.com) and Company B (domain-b.com), and someone
sends an email to `invalid@domain-b.com`, the bounce email saying "Please contact us..."
would be signed by "Company A" because Odoo uses `self.env.company`.

**Solution:**
This module patches `message_route` in `mail.thread`. It extracts the domain from
the recipient address, searches for a matching company, and forces this company
into the QWeb rendering context of the `mail.mail_bounce_catchall` template.

Installation
============

This module is a standard Odoo module. Simply install it via the Apps menu.

Configuration
=============

No specific configuration is required. Ensure your companies have the correct
email addresses set, as the module matches the incoming email domain against
`res.company.email` or `res.company.name`.
